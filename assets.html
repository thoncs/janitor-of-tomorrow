JANITOR OF TOMORROW — asset catalog

Every asset in the game — art: PUDD-CO Graphics Division. The cast (heroes, goos, portraits, GLAZE, K.E.V.I.N.) is generated with PixelLab from the studio's character bible; everything else is authored in-engine.

To reskin: every sprite is one embedded image in the ART block of index.html — find key:'data:image/…' and swap the data URI. Keep the same aspect ratio; the blit size in code stays put, so the game plays identically. Hit-flash variants are generated automatically at load.
